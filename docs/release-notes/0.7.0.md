## For the NGO staff — the console and sender

- **A link in a notice can become an attachment.** When the message on the Send page contains a link
  to a PDF or a picture, the first such link is shown in the app as the notice's attachment. The
  link stays in the text as well. The confirmation after sending says "(with the PDF attached)" or
  "(with the picture attached)"; if it says neither, the link was a web page, missing, or not a file
  the app can show.
- **Saved messages are in number order.** "10." now comes after "9.", not after "1.".
- **The two pages link to each other.** The console's top bar has "Send a notice", and the Send page
  has "Admin console", once their addresses are set (below).
- **Page titles** now read "Admin - Paramanu Seniors Health" and "Sender - Paramanu Seniors Health",
  with the site's icon.

## Technical, for the record

- **Cards are always open.** The collapsed state, the chevron, `expandedId` / `toggleExpanded` and
  the `action_expand` / `action_collapse` strings are gone. A plain tap outside selection does
  nothing; long-press still selects.
- **The list keeps its place.** `LazyListState` is hoisted above the screen switch in `NoticesApp`;
  it used to be remembered inside `NoticeListScreen`, which leaves composition when the viewer or
  Settings replaces it.
- **No more growing cards.** An attachment's aspect ratio is read from the file header
  (`inJustDecodeBounds`, cached by path and mtime) before Coil decodes it, so its height is reserved
  on the first frame.
- **Attachment fetch jitter is 0–60 seconds**, down from 0–120.
- **Sender:** `messageAttachment_` HEADs up to three links in a compose-page message and sends the
  first PDF or JPEG/PNG/WebP/GIF as `pdfUrl` (with `pdfBytes` from Content-Length) or `imageUrl`. A
  missing or generic type falls back to the extension; 404 and 410 are never attached; a failure
  never blocks the send.
- **Both consoles:** `labelOrder_` sorts saved messages with digit runs compared by value, written
  out rather than relying on `localeCompare`'s numeric option.
- **Self-tests** now send to `test-notices-v1`, so a test-disp phone shows the `[selftest]` notices.
- **Room schema unchanged at version 4.**

### Not in the bundle

   `enableCode` back to `revoked: null`.
2. Script Properties: in the console, check `SENDER_URL` is still the sender's current `/exec` URL
   (it is left over from the old revoke bridge and now only drives the link). In the sender, add
   `ADMIN_URL`.
3. Deploy a new version of each; run `runAllTests` in the sender.
