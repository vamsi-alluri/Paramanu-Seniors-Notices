Activation codes

Each code works once. Hand one slip to each person at the counter. Codes never contain the letters I, L, O or U.
Printing covers every code that has not been used or printed yet, not only the page shown below. Printed codes are marked as such, so the next run does not repeat them.
Printing is turned off (Script Properties → PRINTING_ENABLED).

Dispensary banner

Shown at the top of the app, above the notices. Paste straight from Word or Gmail if you like: bold, underline, text colour and highlight are kept, everything else is cleaned away. Text size is deliberately not kept — the app uses whatever size the reader has set on their own phone. Keep it short: the banner travels inside the message sent to every phone, which has a size limit.
